# Sujal Nag — Developer Portfolio

Personal portfolio and showcase for **Sujal Nag** (Computer Science Engineer, Backend & Full Stack Developer).

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **UI & Styling**: Vanilla CSS + Tailwind CSS + Framer Motion
- **Headless CMS Support**: Sanity CMS
- **Icons & Visuals**: Lucide Icons, Custom SVG Thumbnails

- **Junior Full Stack Developer Intern** @ Yuva Intern (React, AWS EC2, Jest)

## Running Locally

```bash
npm install

```
